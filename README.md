# Welcome to Chael's GitHub! 👋

I am **GANZA CHAEL**, a cybersecurity enthusiast and full-stack developer passionate about understanding how systems work, how they can fail, and how to build them better.

My interests sit at the intersection of **software engineering and cybersecurity**. I enjoy building web applications, designing backend systems, working with APIs and databases, and then looking at those same systems from a security perspective to identify weaknesses and improve their resilience.

I believe that understanding how to build systems makes you a better security researcher — and understanding how systems can be broken makes you a better engineer.

---

## 🚀 What I Do

### 💻 Full-Stack Development

- Build **full-stack web applications** from backend APIs to frontend interfaces.
- Design and develop **RESTful APIs** and backend services.
- Work with **databases, authentication, authorization, and role-based access control**.
- Build applications using modern JavaScript/TypeScript and Java ecosystems.
- Develop responsive and functional frontend interfaces while connecting them to secure backend services.
- Work with Git and GitHub for collaborative software development.
- Explore scalable backend architectures and modern software engineering practices.

### 🔐 Cybersecurity

- Perform **web application and API security testing**.
- Identify vulnerabilities and analyze their potential impact.
- Study **penetration testing, vulnerability assessment, and offensive security**.
- Participate in **CTFs** and hands-on security challenges.
- Analyze applications from an attacker's perspective to understand how they can be compromised.
- Build and use custom security tools for research and authorized testing.

### 🧠 Engineering Mindset

I enjoy taking systems apart to understand how they work, rebuilding them when necessary, and finding ways to make them more secure, reliable, and efficient.

Whether I'm writing an API, designing a database, building a web application, or testing an authentication system, I am always interested in understanding what happens underneath the surface.
